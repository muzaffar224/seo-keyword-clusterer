# Contributing

Thank you for considering a contribution.

1. Open an issue describing the bug or improvement before large changes.
2. Fork the repository and create a feature branch.
3. Add tests for behavior changes and run `python -m unittest discover -s tests -v`.
4. Open a pull request with a clear explanation and a small input/output example.

Please avoid uploading private client keyword datasets, credentials, or copyrighted materials without permission. Be respectful in issues and pull requests.
